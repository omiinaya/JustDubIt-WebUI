# Contributing

Thanks for your interest in contributing to JustDubIt-WebUI!

## Getting Started

```bash
git clone https://github.com/omiinaya/JustDubIt-WebUI.git
cd JustDubIt-WebUI

# Install dependencies
pip install -e .
# or
pip install -r requirements.txt
```

## Development

- Python 3.11+
- Flask 3.0
- Formatting: `ruff format`
- Linting: `ruff check`

## Commit Messages

```
type: concise subject
```

Types: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`, `test:`, `ci:`
