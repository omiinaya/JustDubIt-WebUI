# Usage Guide

## Web Interface

1. Open http://your-server:5000
2. Upload video (MP4, AVI, MOV, MKV, WEBM)
3. Enter prompt: `The person is speaking Spanish, saying: "Hola"`
4. Adjust settings (optional)
5. Click "Start Dubbing"
6. Wait 10-30 minutes
7. Download result

## Prompt Format

Best format: `The [person] is speaking [Language], saying: "[Text]"`

## Settings

- Height/Width: Stage 1 resolution (512x768 → 1024x1536 output)
- Steps: 10-100 (30 default)
- CFG: 1.0-10.0 (3.0 default)
- FPS: 15-60 (25 default)
